## 本次代码核验发现的接入差距

1. 扫描调用为 `startScan(null, ...)`，UUID 仅在回调解析时过滤。需要增加有效 ScanFilter 并做熄屏实测；不能认为回调内过滤已解决系统无过滤扫描的熄屏行为。
2. `onScanFailed` 尚未处理，权限/扫描异常多处直接返回或捕获后忽略，需要可观测错误状态。
3. 空窗口仅在手表显示“未检测到信标”并返回，不发送空观测；需联动主机检查位置过期、unknown/stale 和旧位置保留规则，不能只改一端。
4. 当前载荷仅含 beacon_id/rssi，缺样本数和采样时刻等诊断字段。新增字段须按原 MQTT 协议兼容扩展、配套测试，不另建平行协议。
5. 现有定位是区域级。真实信标与房间/楼层的映射尚需现场确认；演示房间/楼层不能直接替代高新店24F底图。3D 精确坐标能力仍未取得。
