# 换机恢复备份服务

1. 使用有权限的 GitHub 账号确认仓库 PRIVATE，独立 clone main 或已知 checkpoint。先运行 tools/verify_backup.py，再读交接说明和验证记录；不要覆盖旧工作区或生产数据库。
2. 安装 Python 3.9+、Git、已授权 SSH/gh 身份。场景预览仅需 Python HTTP 服务与浏览器；Blender 编辑需另装 Blender，浏览器 CDN 依赖需验证。不要把私钥存入仓库。
3. 在新机安全目录 `~/.banyuexuan-project-sync/` 创建权限受限的 repos 目录，使用本目录 source_sync.py 作为同步器。
4. 创建 projects.json，至少包含下例，将 source 改为新机实际权威目录。共享服务已有其他项目时只合并 digital 条目，不覆盖其他项目。

```json
[{"id":"digital","name":"伴月轩数字孪生高新店","source":"/新机权威目录/伴月轩数字孪生高新店","repo":"Alston3825/banyuexuan-digital-twin-gaoxin","existing":false}]
```

5. **若同步镜像不存在，先用 git clone 将已有远端 main 克隆到 repos/digital**，不要在有历史的远端新建不相干 Git 历史。配置 Git 提交身份。运行 `python3 tools/backup_checkpoint.py`，核对远端 main 与检查点 SHA。
6. 在 Codex 中按备份计划恢复四次自动任务；launchd 五分钟同步按本机目录重新登记，并验证实际执行。任务 ACTIVE 不能当作运行成功。旧服务路径和旧 Mac 私钥不能假定存在。

本目录脚本是恢复副本，不包含用户账号、部署配置、私钥、生产数据或模型。不要在换机恢复时重跑现场 N100 首次初始化。
