# 资料覆盖与缺口

## 本仓库安全快照包含

- 三版场景的 Blender、CAD、效果图、网页 HTML/JavaScript、六个 b64 模型及脚本；项目既有房间/家具/工服参考资料。
- 根开发约定、README、需求/开发进展、定位接口/现场标定/实机核验文档、工具及测试。
- `资料/设备说明/BeaconSET用户操作手册.pdf`：从用户桌面复制，避免跨 AI 接手依赖临时路径。
- `备份与交接/` 中手工交接、每日快照、自动索引、计划、验证记录、服务脚本副本与恢复说明；镜像自动生成的源文件 SHA256 清单。

## 不进入安全源码备份

- `local-private/` 的真实设备 MAC/身份、原手表视频及抽帧、现场采样、未来真实配置；不上传私钥、真实 .env、密码、数据库、客户资料。
- 依赖、缓存、构建目录、安装包、日志、压缩归档及模型权重；CI 工作流以文本备份，避免源码备份触发自动发布。
- 呼叫定位项目独立源码在其私有仓库，本项目仅保留接口/路径/版本依据。不能只 clone 本仓库就宣称恢复了关联主机、APK 和现场业务数据。

## 已知缺口与历史问题

旧同步器自定义遍历不遵循 `.gitignore`，已发现真实设备记录及手表视频/抽帧进入此前私有镜像。此次增加明确排除，并从最新 main 快照移除；**旧提交仍可能保留这些文件**。未发现这些文件包含私钥/密码的证据，但不能把历史说成已清理，也不擅自 force push 重写历史。历史清理如有需要应另行设计并明确授权。

本机私有资料尚未建立独立加密灾备，不保证换机后能自动恢复这些文件。生产数据库、部署配置、签名/账号/密钥也不在本仓库，恢复需用户安全提供；不得从示例生成真实账号或覆盖现场配置。

源码备份采用镜像独立提交历史，不保存当前工作目录的 Git 暂存区或未提交状态元数据；文件内容可恢复。每轮恢复仍须重跑测试，自动备份不等于软件验收或已上线。
