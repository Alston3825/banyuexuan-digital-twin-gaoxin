### 本地打开网页
直接双击打开会读不到模型文件。可以在 `网页实时3D` 文件夹里打开终端，运行：

```
python3 -m http.server 8000
```

然后在浏览器访问 `http://localhost:8000`。正式使用时，把整个文件夹放到店里的服务器上就可以（比如护理站那台 N100 主机）。

## 这一版新增

1. **动作按区域约束。** 每个人物每一帧都会查一张「岗位 × 所在区域 × 活动 → 动作」规则表。在页面左下角点「动作规则」可以看到整张表。目前的规则：
   - 护理部
     - 走廊里：走路；抱着宝宝时是抱持姿势。
     - 游泳抚触室：俯身给宝宝游泳洗澡，宝宝在泳池里；在抚触台做抚触。
     - 托管室和客房：抱宝宝喂奶，一只手抱宝宝，一只手拿奶瓶。
     - 护理站：值守操作。
   - 餐饮部（送餐员）
     1. 从饭菜加热区出来，推着送餐车沿走廊走。
     2. 到房门口把车停靠在墙边，弯腰从餐车取餐。
     3. 端着餐盘进房间，送到茶几旁。
     4. 回到餐车，推去下一间。每趟送 3 间。
   - 保洁部：在房间和走廊里做擦拭动作。
   - 销售部：在前台接待；带客户参观时挥手讲解。

   以后要加动作，只需要在规则表里加一行。例如「护理部 · 客房 · 换尿布 → 弯腰护理」，人物模型里再补一个对应的动作即可。规则表在 `index.html` 里搜索 `RULES` 就能找到。

2. **行走的物理约束。**
   - **不穿墙、不穿家具：** 通行网格从 Blender 整层模型直接算出来，精度 10 cm。墙、玻璃隔断和家具都算障碍；地毯、窗帘不算。人物只在这张网格上规划路线（A* 寻路），路线尽量走在过道中间。
   - **人与人不重叠：** 人物之间始终保持距离，实测连续运行 25 分钟，任何两人最近都没有低于 0.52 m。相向而行时会靠右让行，被挡住会绕行。站着没事做的同事挡路时，会主动让到一边。
   - **一间客房同一时间只进一位员工：** 客房空间小，如果房里已经有同事，后来的人在门口等，头顶会显示「等 24xx 房里的同事出来」。
   - **送餐车停靠在本侧墙边：** 走廊两侧同时停车，中间也能过人。
   - 打开左下角「路径规划」和「通行网格」，可以直接看到每个人规划的路线和可通行区域。

3. **右上角的天气与时间。**
   - 时间和日期跟随电脑的实时时钟。
   - 天气目前是演示模式。点击天气卡片可以切换晴、多云、阴、小雨，场景的光线会随之变化，下雨时画面上会有雨丝。
   - 对接真实天气，只要在网址后面加参数，二选一：
     - 和风天气：`?qweather=你的KEY&loc=城市ID&city=显示名`
     - 墨迹天气（阿里云市场）：`?moji=你的APPCODE&loc=城市ID&city=显示名`

     天气每 20 分钟刷新一次。
   - 预览链接所在的平台不允许页面访问外部网址，所以真实天气要等部署到你们自己的服务器上才会生效。

4. **界面字体。** 伴月轩名字、时间、在岗人员等界面上的文字，统一改成思源黑体（Noto Sans SC）细体。

## 11-12：人员拥堵的处理（网页实时 3D）

- **问题：** 走廊里有时会几个人互相挡住、挤成一团，最长卡住过 3 分多钟，多发生在送餐车会车、护理站和托管室门口这几处。
- **一、谁先走：** 每 0.5 秒检查一次谁被堵住了。只要有两人以上互相挡住，按优先级定一个人先走：
  - 推餐车的最优先；
  - 其次是手上抱宝宝、端餐盘的；
  - 再次是正在执行任务的；
  - 最后是空手走路的。
- **二、其他人让路：** 其他人退到旁边不挡路的位置，头顶显示「让 某某 先过」。等先走的人离开 2.6 米后再继续走，最多等 12 秒。
- **三、两辆餐车会车：** 两辆餐车在走廊里迎面相遇、相距 5 米以内时，后面那辆提前靠边停下，等前一辆过去，不等到车头顶车头才处理。
- **四、兜底：**
  - 如果有人让路的路线本身也被堵住，6 秒后放弃让路、继续原来的任务。
  - 如果有人连续 8 秒走不动，周围 2.2 米内的同事都给他让路。
- **效果：** 同样连续模拟 30 分钟，每人每秒累计被堵的时间从 122～1529 秒降到 1～28 秒，最长一次卡住从 36～210 秒降到 9 秒以内。完成的任务数没有减少，人与人之间仍然保持 0.52 米以上，没有人穿墙。
